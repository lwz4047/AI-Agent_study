# Python 模块（Module）学习文档

> 本文档基于 `模块/` 目录下的 `my_module.py` 与 `py_module.py` 整理而成。

---

## 一、什么是模块？

**模块（Module）** 就是一个 `.py` 文件。  
把功能性的代码单独写在一个文件里，其他文件可以通过 `import` 导入并使用，这个文件就叫做模块。

> 模块的本质：**代码复用的基本单位**。

---

## 二、模块的组成

一个标准的模块文件通常包含以下内容（参考 `my_module.py`）：

```python
# my_module.py

# 1. 模块级变量
module_name = "工具模块"

# 2. 函数定义
def add(a, b):
    return a + b

def greet(name):
    print(f"你好呀！{name}!")

# 3. __name__ 保护块（仅在本文件直接运行时执行）
print("my_module模块中的内置全局变量__name__:", __name__)
if __name__ == "__main__":
    print(add(1, 2))
```

---

## 三、导入模块的四种方式

### 方式一：`import 模块名`

```python
import my_module

# 使用方式：模块名.功能
result = my_module.add(2, 4)
print(result)           # 6
print(my_module.module_name)  # 工具模块
```

**特点：** 命名空间清晰，不会与当前文件的变量冲突，**推荐使用**。

---

### 方式二：`import 模块名 as 别名`

```python
import my_module as mm  # 给模块起别名

result = mm.add(2, 4)
print(result)  # 6
```

**特点：** 模块名较长时，用别名简化书写；同时防止命名冲突。

---

### 方式三：`from 模块名 import 功能名`

```python
from my_module import add, module_name, greet

# 使用时直接写功能名，无需加模块名前缀
result = add(1, 2)
print(result)       # 3
print(module_name)  # 工具模块
greet("小明")       # 你好呀！小明!
```

**特点：** 使用更简洁，但若当前文件也有同名变量，会发生**覆盖冲突**。

---

### 方式四：`from 模块名 import *`（导入所有）

```python
from my_module import *

# 导入模块中所有公开的名称
print(module_name)  # 工具模块
greet("小红")       # 你好呀！小红!
```

**特点：** 方便但危险，容易污染命名空间，**不推荐在大型项目中使用**。  
可通过模块内的 `__all__` 变量限制 `*` 导入的范围（见第六节）。

---

## 四、`__name__` 变量详解

`__name__` 是 Python 每个模块都内置的全局变量，它的值取决于模块的运行方式：

| 运行方式 | `__name__` 的值 |
|----------|----------------|
| 直接运行该文件 | `"__main__"` |
| 被其他文件导入 | `"模块文件名"`（如 `"my_module"`） |

### 验证示例

`my_module.py` 中有这行代码：

```python
print("my_module模块中的内置全局变量__name__:", __name__)
```

- **直接运行 `my_module.py`** 时，输出：
  ```
  my_module模块中的内置全局变量__name__: __main__
  ```

- **在 `py_module.py` 中 `import my_module`** 时，输出：
  ```
  my_module模块中的内置全局变量__name__: my_module
  ```

### `if __name__ == "__main__":` 的作用

```python
if __name__ == "__main__":
    # 这段代码只在【直接运行】该文件时执行
    # 被其他模块 import 时，这段代码【不会】执行
    print(add(1, 2))
```

> **最佳实践：** 把测试代码、调试代码都放在 `if __name__ == "__main__":` 块内，
> 防止被其他模块导入时意外执行。

---

## 五、导入模块时的执行机制

**重要：** 导入模块时，Python 会**执行该模块文件中的所有顶层代码**。

参考 `py_module.py` 最后一行：

```python
import my_module  # 导入时，会执行 my_module.py 中所有顶层代码
```

执行后，`my_module.py` 顶层的 `print(...)` 语句会被立即触发。  
这正是为什么需要用 `if __name__ == "__main__":` 来保护测试代码。

## 六、命名冲突问题与解决

当导入的模块变量名与当前文件变量名相同时，会产生覆盖：

```python
module_name = "py_module"   # 当前文件的变量

import my_module            # my_module 里也有 module_name = "工具模块"

# 使用本模块的变量
print(module_name)          # py_module（本文件的）

# 使用工具模块的变量（需加模块名前缀）
print(my_module.module_name) # 工具模块
```

> **结论：** `import 模块名` 的方式不会污染命名空间，比 `from 模块名 import *` 更安全。

## 七、标准库模块示例

Python 内置了大量标准库模块，直接 `import` 即可使用。

### random 模块 —— 生成随机数

```python
import random

# 生成 1 到 100 之间的随机整数
num = random.randint(1, 100)
print(num)        # 例如：42
print(type(num))  # <class 'int'>
```

### requests 模块 —— 网络请求（第三方库）

> 需先安装：`pip install requests`

```python
import requests

# 爬取百度首页内容
response = requests.get('https://www.baidu.com')
response.encoding = 'utf-8'
print(response.text)  # 输出百度首页的 HTML 源码
```

## 八、知识点汇总

| 知识点 | 说明 |
|--------|------|
| 模块 | 一个 `.py` 文件就是一个模块 |
| `import 模块名` | 导入整个模块，使用时需加 `模块名.` 前缀 |
| `import 模块名 as 别名` | 给模块起别名，简化书写 |
| `from 模块名 import 功能` | 直接导入指定功能，使用时无需前缀 |
| `from 模块名 import *` | 导入所有公开功能，慎用 |
| `__name__` | 直接运行时为 `__main__`，被导入时为模块名 |
| `if __name__ == "__main__"` | 保护测试代码，防止被导入时意外执行 |
| 导入时执行 | `import` 模块时，模块内顶层代码会被执行一次 |

## 九、补充：模块搜索路径

Python 导入模块时，按以下顺序搜索：

1. **当前目录**（脚本所在目录）
2. **环境变量 `PYTHONPATH`** 指定的目录
3. **Python 标准库目录**
4. **第三方库目录**（如 `site-packages`）

可以通过 `sys.path` 查看当前搜索路径：

```python
import sys
print(sys.path)
```

如果自定义模块不在以上路径中，导入时会报 `ModuleNotFoundError`。  
解决方法：把模块文件放在当前脚本同级目录，或者将路径添加到 `sys.path`：

```python
import sys
sys.path.append("你的模块所在目录")
import my_module
```

## 十、模块缓存机制

Python 导入模块时，会将其缓存到 `sys.modules` 字典中。  
**同一个模块无论被 `import` 多少次，其顶层代码只执行一次。**

```python
import sys

import my_module   # 第一次：执行模块内顶层代码，并缓存
import my_module   # 第二次：直接从缓存读取，不再执行代码

# 查看已缓存的模块
print("my_module" in sys.modules)  # True
```

### 强制重新加载模块

如果模块文件在运行期间被修改，可以用 `importlib.reload()` 强制重新加载：

```python
import importlib
import my_module

# 假设 my_module.py 已被修改
importlib.reload(my_module)  # 重新执行模块代码，刷新缓存
```

> **注意：** `reload()` 只在调试、热更新场景下使用，正常业务代码不需要。

## 十一、查看模块信息

Python 为每个模块内置了若干属性，方便查看模块的元信息：

```python
import my_module

# 模块名称
print(my_module.__name__)   # my_module

# 模块文件的绝对路径
print(my_module.__file__)   # D:\python\py_project\模块\my_module.py

# 查看模块中所有可用的名称（变量、函数、类等）
print(dir(my_module))
# ['__builtins__', '__doc__', '__file__', '__name__', 'add', 'greet', 'module_name', ...]
```

### 模块文档字符串 `__doc__`

在模块文件开头写三引号字符串，就是该模块的文档字符串：

```python
# my_module.py
"""这是工具模块，提供 add 和 greet 两个功能函数。"""

def add(a, b):
    """返回 a + b 的结果。"""
    return a + b
```

```python
import my_module

# 查看模块文档
print(my_module.__doc__)        # 这是工具模块，提供 add 和 greet 两个功能函数。

# 查看函数文档
print(my_module.add.__doc__)    # 返回 a + b 的结果。

# 也可以用内置的 help() 函数查看
help(my_module)
```

## 十二、常用标准库模块速查

Python 自带了丰富的标准库，无需安装即可使用：

| 模块 | 用途 | 常用功能示例 |
|------|------|--------------|
| `os` | 操作系统接口 | `os.getcwd()`、`os.listdir()`、`os.path.join()` |
| `sys` | Python 解释器接口 | `sys.path`、`sys.argv`、`sys.exit()` |
| `math` | 数学函数 | `math.sqrt()`、`math.pi`、`math.ceil()` |
| `random` | 随机数生成 | `random.randint()`、`random.choice()`、`random.shuffle()` |
| `datetime` | 日期和时间 | `datetime.date.today()`、`datetime.datetime.now()` |
| `json` | JSON 数据处理 | `json.dumps()`、`json.loads()` |
| `re` | 正则表达式 | `re.match()`、`re.findall()`、`re.sub()` |
| `time` | 时间操作 | `time.sleep()`、`time.time()` |
| `pathlib` | 现代路径操作 | `Path.cwd()`、`Path.exists()`、`Path.read_text()` |
| `copy` | 对象复制 | `copy.copy()`（浅拷贝）、`copy.deepcopy()`（深拷贝） |

### 示例：`os` 与 `datetime`

```python
import os
import datetime

# 获取当前工作目录
print(os.getcwd())

# 列出目录下的所有文件
print(os.listdir("."))

# 拼接路径（自动适配 Windows / Linux）
path = os.path.join("my_package", "calc.py")
print(path)  # my_package\calc.py（Windows）

# 获取当前时间
now = datetime.datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))  # 例如：2026-08-20 10:30:00
```

## 十三、常见错误与解决

| 错误类型 | 原因 | 解决方法 |
|----------|------|----------|
| `ModuleNotFoundError` | 模块不在搜索路径中 | 检查文件名、路径，或添加到 `sys.path` |
| `ImportError` | 模块中没有该名称 | 检查拼写，用 `dir()` 查看可用名称 |
| `AttributeError` | 用 `from import` 后仍用模块名前缀 | 去掉模块名前缀，直接用功能名 |
| 重复执行顶层代码 | 没有 `if __name__ == "__main__"` 保护 | 将测试代码放入保护块内 |
| 循环导入 `ImportError` | 模块 A 导入 B，B 又导入 A | 重构代码，提取公共部分到第三个模块 |
