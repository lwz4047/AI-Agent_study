# 学员信息管理系统（函数版）

`student_xinxi.py` 是一个基于**函数封装**思想实现的命令行学员信息管理系统，用于练习字典、列表、函数、循环、分支等 Python 基础知识的综合应用。

## 一、程序功能

程序启动后会展示功能菜单，用户输入序号（1-6）选择对应操作：

| 序号 | 功能 | 实现状态 |
|------|------|----------|
| 1 | 添加学员 | ✅ 已实现 |
| 2 | 删除学员 | ⏳ 待实现（占位） |
| 3 | 修改学员 | ⏳ 待实现（占位） |
| 4 | 查询学员 | ⏳ 待实现（占位） |
| 5 | 显示所有学员 | ⏳ 待实现（占位） |
| 6 | 退出系统（二次确认） | ✅ 已实现 |

## 二、数据结构设计

- **单个学员信息**：使用 `dict` 存储，包含 `id`（学号）、`name`（姓名）、`tel`（手机号）三个字段
- **所有学员信息**：使用 `list` 存储多个学员字典，即 `info = []`

```python
info = [
    {"id": "1001", "name": "张三", "tel": "13800000000"},
    {"id": "1002", "name": "李四", "tel": "13900000000"},
    ...
]
```

> 设计思路：**多个学员信息用列表，单个学员信息用字典** —— 列表存字典是管理一组结构化数据的常用模式。

## 三、函数说明

### `info_print()`

打印功能菜单界面，不接收参数、不返回值，仅负责展示。

### `add_info()`

添加学员信息，核心逻辑：

1. 通过 `input()` 依次收集学号、姓名、手机号
2. **遍历 `info` 列表**，判断学号是否已存在（避免重复添加）
   ```python
   for student in info:
       if new_id == student['id']:
           print(f"该学员{new_name}已存在！无法重复添加")
           return   # 提前返回，终止函数
   ```
3. 若不存在，将三项信息组装成字典 `student_dict`，通过 `info.append()` 加入列表
4. 打印添加成功提示

## 四、主程序流程

```python
info_print()          # 程序启动先展示一次菜单

while True:            # 不知道循环次数，但知道结束条件 → while True + break
    user_num = int(input("请输入功能序号（1-6）："))
    if user_num == 1:
        add_info()
    elif user_num == 6:
        exit_config = input("确定要退出吗？yes or no")
        if exit_config == "yes":
            break      # 用户确认后才真正退出循环
    else:
        print("输入有误，请重新输入")
```

- **循环控制**：使用 `while True` 死循环 + `break` 实现"直到用户主动退出"的交互模式，适用于**循环次数不确定、但退出条件明确**的场景
- **分支路由**：用 `if / elif / else` 将序号映射到具体功能函数，是命令行菜单程序的典型写法
- **退出二次确认**：输入 `6` 后需再输入 `yes` 才会真正 `break` 退出，避免误触

## 五、涉及的知识点

| 知识点 | 说明 |
|--------|------|
| 字典 `dict` | 存储一条结构化的学员信息（键值对） |
| 列表 `list` | 存储多条学员信息，支持 `append()` 追加 |
| 函数定义 | 用 `def` 拆分"界面展示"和"添加逻辑"，提高代码复用性和可读性 |
| `for` 遍历 + 提前 `return` | 遍历列表查重，命中即用 `return` 终止函数，避免继续执行添加逻辑 |
| `while True` + `break` | 处理循环次数不确定、依赖条件判断退出的场景 |
| `if / elif / else` 多分支 | 根据用户输入的序号路由到不同功能 |
| f-string | `f"该学员{new_name}已存在！"` 等格式化输出 |
