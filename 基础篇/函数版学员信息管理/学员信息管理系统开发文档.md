# student_xinxi.py — 学员信息管理系统开发文档

## 一、项目概述

`student_xinxi.py` 是一个命令行交互的**学员信息管理系统（函数版 V1.0）**，所有功能均已实现。程序运行后展示菜单，用户输入序号（1-6）操作学员数据，支持添加、删除、修改、查询、显示全部、退出六项功能。

## 三、数据结构

- **单条学员信息**：`dict`，包含三个字段

  | 键 | 含义 | 类型 |
  |----|------|------|
  | `id` | 学号 | str |
  | `name` | 姓名 | str |
  | `tel` | 手机号 | str |

- **全部学员**：`list`，存放多个学员字典，初始为空列表 `info = []`

```python
info = [
    {"id": "1001", "name": "张三", "tel": "13800000001"},
    {"id": "1002", "name": "李四", "tel": "13800000002"},
]
```

## 四、函数详解

### `info_print()` — 显示菜单界面

打印系统标题和 6 个功能选项，无参数，无返回值，程序启动时调用一次。

---

### `add_info()` — 添加学员

**做了什么：**
1. 用 `input()` 收集学号、姓名、手机号
2. 遍历 `info`，若学号已存在则提示并 `return` 中止，防止重复添加
3. 将三项信息组装为字典，`info.append()` 写入列表，打印添加成功

```python
def add_info():
    new_id = input("请输入学号：")
    new_name = input("请输入学员姓名：")
    new_tel = input("请输入手机号：")
    for student in info:
        if new_id == student['id']:
            print(f"该学员{new_name}已存在！无法重复添加")
            return
    student_dict = {"id": new_id, "name": new_name, "tel": new_tel}
    info.append(student_dict)
    print(f"添加成功！学员信息{student_dict}")
```

---

### `dele_info()` — 删除学员

**做了什么：**
1. 用 `input()` 收集要删除的姓名
2. 遍历 `info`，找到同名学员后用 `info.remove(student)` 删除，打印剩余列表并 `return`
3. 遍历结束未找到则提示错误

```python
def dele_info():
    del_name = input("请输入要删除的学员的姓名：")
    for student in info:
        if del_name == student["name"]:
            info.remove(student)
            print(f"删除成功！已删除【{del_name}】的学员信息")
            return
    print(f"错误：未找到姓名为【{del_name}】的学生")
```

---

### `modify_info()` — 修改学员

**做了什么：**
1. 用 `input()` 收集要修改的学员姓名
2. 遍历 `info` 找到该学员，依次让用户重新输入学号、姓名、手机号，直接覆盖字典字段
3. 修改完成后打印当前全部数据并 `return`
4. 未找到则提示

```python
def modify_info():
    modify_name = input("输入修改的学员姓名：")
    for student in info:
        if modify_name == student["name"]:
            student["id"] = input("请输入新的学号：")
            student["name"] = input("请输入新的姓名：")
            student["tel"] = input("请输入新的号码：")
            print(f"修改成功，{info}")
            return
    print(f"未找到该学员，{modify_name}")
```

---

### `search_info()` — 查询学员

**做了什么：**
1. 用 `input()` 收集要查询的学员姓名
2. 遍历 `info` 找到同名学员，格式化打印学号、姓名、手机号后 `return`
3. 未找到则提示

```python
def search_info():
    search_name = input("请输入要查询的学员姓名：")
    for student in info:
        if search_name == student["name"]:
            print("=" * 20)
            print(f"学号：{student['id']}")
            print(f"姓名：{student['name']}")
            print(f"号码：{student['tel']}")
            print("=" * 20)
            return
    print(f"没找到该{search_name}学员！")
```

---

### `print_info()` — 显示所有学员

**做了什么：**
1. 打印格式化表头（学号 / 姓名 / 手机号）
2. 遍历 `info`，逐行输出每位学员数据，用 `\t` 对齐，手机号右对齐宽度 10

```python
def print_info():
    print("=" * 34)
    print("学号\t\t姓名\t\t手机号")
    print("-" * 34)
    for student in info:
        print(f"{student['id']}\t\t{student['name']}\t\t{student['tel']:>10}")
    print("-" * 34)
```

## 五、主程序逻辑

```
启动
  ↓
info_print()  ← 展示菜单
  ↓
while True
  ├─ 输入 1 → add_info()      添加学员
  ├─ 输入 2 → dele_info()     删除学员
  ├─ 输入 3 → modify_info()   修改学员
  ├─ 输入 4 → search_info()   查询学员
  ├─ 输入 5 → print_info()    显示所有学员
  ├─ 输入 6 → 二次确认（y）→ break → 退出
  └─ 其他  → 提示输入有误，继续循环
```

- 使用 `while True + break` 处理"不确定循环次数、依赖条件退出"的场景
- 退出前二次确认（输入 `y`），防止误触

## 七、总结

### 本项目练习了哪些知识点

| 知识点 | 在项目中的体现 |
|--------|---------------|
| `list` 列表 | `info = []` 存储所有学员，`append()` 添加，`remove()` 删除 |
| `dict` 字典 | 每位学员的 `id / name / tel` 用字典存储，支持按键读写 |
| `def` 函数封装 | 6 个功能各自封装成独立函数，逻辑清晰、互不干扰 |
| `for` 遍历 | 所有增删改查操作都通过遍历 `info` 列表实现 |
| 提前 `return` | 找到目标后立即 `return`，避免无效的继续遍历 |
| `while True + break` | 主循环保持程序运行，退出时才 `break` |
| `if / elif / else` | 菜单序号路由到对应函数 |
| f-string | 所有提示、结果输出均使用 f-string 格式化 |
| `\t` 与 `:>10` | 表格输出对齐：`\t` 制表符对齐列，`:>10` 右对齐手机号 |

### 开发收获

1. **函数封装**让代码从"一大段流水式代码"变成"模块化功能"，每个函数只做一件事，出问题也更容易定位
2. **列表 + 字典**的组合是 Python 中管理一组结构化数据最常用的方式，本项目是这一模式的典型实践
3. **遍历 + 提前 return** 是"查找后操作"的标准写法：找到就处理并退出，找不到才在循环后给出提示
4. **`while True + break`** 是命令行交互程序的核心骨架，配合 `if / elif` 分支可以构建任何菜单驱动的程序
