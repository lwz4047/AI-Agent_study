## 一、文件操作概述

**文件操作**指程序对磁盘上文件进行「读、写、追加、关闭」等处理。基本流程为三步：

1. **打开文件** → `open()`，得到一个文件对象；
2. **读 / 写文件** → 对文件对象调用 `read` / `write` 等方法；
3. **关闭文件** → `close()`，释放系统资源。

> 记忆口诀：**打开 → 操作 → 关闭**。

---

## 二、打开与关闭文件

**语法：** `文件对象 = open(文件路径, 模式, encoding=编码)`

```python
# 文本文件：指定 utf-8 编码，只读格式
f = open("test.txt", "r", encoding="utf-8")   # f 为文件对象
print(f.read())                               # 读取全部内容
f.close()                                     # 关闭文件（务必记得）
```

**要点说明：**

| 参数 | 说明 |
|------|------|
| `文件路径` | 要操作的文件位置，可以是相对路径或绝对路径 |
| `模式` | 打开方式，如 `"r"`（只读）、`"w"`（只写），默认是 `"r"` |
| `encoding` | 文件编码，处理中文时建议显式写 `encoding="utf-8"` |

> **注意：** 手动 `open()` 后一定要 `close()`，否则可能造成资源泄漏、数据未刷新等问题。

---

## 三、`with` 上下文管理器（推荐）

`with open(...) as f:` 会在代码块结束后**自动关闭文件**，即使中途发生异常也不例外，是**最推荐**的写法。

```python
with open("test.txt", "r", encoding="utf-8") as f:
    print(f.encoding)      # 读写操作：查看编码 utf-8
print(f.closed)            # 离开 with 代码块后自动关闭，输出 True
```

**对比：**

| 写法 | 是否需要手动关闭 | 异常安全 | 推荐度 |
|------|:---------------:|:-------:|:------:|
| `f = open()` … `f.close()` | 需要 | 否 | ⭐⭐ |
| `with open() as f:` | 自动 | 是 | ⭐⭐⭐⭐⭐ |

## 四、文件的打开模式

| 模式 | 含义 | 能读 | 能写 | 打开时是否清空原内容 | 文件不存在时 |
|------|------|:----:|:----:|:------------------:|-------------|
| `"r"` | 只读（默认） | ✅ | ❌ | 否 | **报错** |
| `"w"` | 只写 | ❌ | ✅ | **是（清空！）** | 自动创建 |
| `"a"` | 追加写 | ❌ | ✅ | 否（在末尾追加） | 自动创建 |
| `"r+"` | 读写 | ✅ | ✅ | 否 | 报错 |
| `"w+"` | 读写 | ✅ | ✅ | **是（清空！）** | 自动创建 |
| `"a+"` | 读 + 追加 | ✅ | ✅ | 否 | 自动创建 |

> **重点：**
> - 带 `w` 的模式会**先清空文件**，使用前务必确认；
> - 带 `r` 的模式若文件不存在会**报错**；
> - 带 `a` 的模式总是在**文件末尾追加**，不会破坏原内容。

## 五、读取文件

以 `"r"` 只读模式为例，`test.txt` 内容如下：

```
hello world
helle xiaomi
```

### 1. `read()` —— 一次读取全部内容

```python
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()        # 读取全部
print(content)

# read(n)：读取前 n 个字符
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read(1)       # 只读第 1 个字符
print(content)                # h
```

### 2. `readline()` —— 一次读取一行

```python
with open("test.txt", "r", encoding="utf-8") as f:
    line1 = f.readline()      # 第一行（含结尾换行符 \n）
    line2 = f.readline()      # 第二行
print(f"第一行：{line1}", end="")
print(f"第二行：{line2}", end="")
```

### 3. `readlines()` —— 读取所有行，返回列表

```python
with open("test.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()     # ['hello world\n', 'helle xiaomi\n']
print(f"所有行：{lines}")

for line in lines:
    print(line, end="")       # 逐行输出（end="" 避免多打空行）
```

### 4. 直接遍历文件对象（最省内存，推荐）

```python
with open("test.txt", "r", encoding="utf-8") as f:
    for line in f:            # 文件对象可直接迭代，一行一行读
        print(line, end="")
```

**读取方法对比：**

| 方法 | 返回 | 适用场景 |
|------|------|----------|
| `read()` | 整个文件内容字符串 | 文件较小，一次全读 |
| `read(n)` | 前 n 个字符 | 只需读取部分内容 |
| `readline()` | 一行字符串 | 逐行按需读取 |
| `readlines()` | 所有行组成的列表 | 需要随机访问某几行 |
| `for line in f` | 逐行迭代 | 大文件，省内存 |

## 六、写入文件

写入用 `write()` 方法，配合 `"w"` / `"a"` / `"a+"` 等可写模式。

### 1. 只写模式 `"w"`：不存在则创建，存在则**覆盖**

```python
with open("test2.txt", "w", encoding="utf-8") as f:
    f.write("\n小米鹏程N90_MAX")     # 覆盖原有内容
```

### 2. 追加模式 `"a"`：不存在则创建，存在则**在末尾追加**

```python
with open("test3.txt", "a", encoding="utf-8") as f:   # 只能写，不能读
    f.write("\n小米鹏程N90_MAX")     # 不会覆盖旧内容
```

> **提示：** `write()` 不会自动换行，需要换行时自行在字符串里加 `\n`。

## 七、文件指针 `tell` 与 `seek`

**文件指针**就像一个标记，指示下次读 / 写的起始位置。

- `f.tell()`：返回当前指针的位置（字节数）；
- `f.seek(偏移量)`：把指针移动到指定位置，`f.seek(0)` 表示回到文件开头。

```python
with open("test.txt", "a+", encoding="utf-8") as f:   # a+ 可读可追加
    f.write("\n小米汽车，SU7和YU7")
    print("当前指针的位置", f.tell())   # 写入后，指针在末尾
    f.seek(0)                          # 将指针移动到开头
    print("读取内容", f.read())         # 从头读取全部内容
```

**不同模式下指针的初始位置：**

| 模式 | 打开时指针位置 |
|------|---------------|
| `r`、`r+` | 文件**开头** |
| `w`、`w+`、`a`、`a+` | 文件**末尾** |

> **易错点：** 用 `a+` 模式先 `write()` 后直接 `read()` 会读不到内容，因为指针停在末尾；必须先 `f.seek(0)` 把指针移回开头。

## 八、编码 encoding

- 处理**文本文件**时，务必显式指定 `encoding="utf-8"`，避免中文乱码或平台默认编码不一致导致的报错。
- 读取时的编码必须与文件**保存时的编码一致**，否则会出现乱码或 `UnicodeDecodeError`。
- 若要操作**二进制文件**（图片、视频等），模式需加 `b`，如 `"rb"`、`"wb"`，此时不能指定 `encoding`。

## 九、目录（文件夹）操作

> 本节为补充知识，主要使用 Python 内置的 `os` 与 `os.path` 模块。使用前需 `import os`。

### 1. 路径与当前工作目录

```python
import os

print(os.getcwd())                 # 获取当前工作目录
os.chdir("D:/pyProject")           # 切换工作目录
print(os.path.abspath("test.txt")) # 获取某路径的绝对路径
```

### 2. 拼接与拆分路径（跨平台安全）

```python
# 用 os.path.join 拼接路径，自动使用当前系统的分隔符（Windows \ / Linux、Mac /）
path = os.path.join(os.path.dirname(__file__), "test.txt")

print(os.path.dirname("D:/a/b/c.txt"))   # D:/a/b   （取目录部分）
print(os.path.basename("D:/a/b/c.txt"))  # c.txt    （取文件名部分）
print(os.path.splitext("c.txt"))         # ('c', '.txt')  （拆分文件名与扩展名）
```

> **推荐：** 拼接路径优先用 `os.path.join()`，而不是手写 `+ "/"`，这样代码在不同操作系统都能正常运行。

### 3. 判断路径是否存在 / 类型

```python
print(os.path.exists("test.txt"))      # 路径是否存在
print(os.path.isfile("test.txt"))      # 是否为文件
print(os.path.isdir("文件操作"))        # 是否为目录
```

### 4. 列出、创建、删除目录

```python
print(os.listdir("."))             # 列出指定目录下的所有文件和子目录（. 表示当前目录）

os.mkdir("新目录")                  # 创建单层目录（父目录必须已存在）
os.makedirs("a/b/c")               # 递归创建多层目录（父目录不存在也会自动创建）

os.rmdir("新目录")                  # 删除空目录（目录非空会报错）
os.removedirs("a/b/c")             # 递归删除空目录
os.remove("test2.txt")             # 删除文件
os.rename("旧名.txt", "新名.txt")   # 重命名 / 移动文件或目录
```

| 方法 | 作用 | 注意 |
|------|------|------|
| `os.listdir(path)` | 列出目录内容 | 返回列表 |
| `os.mkdir(path)` | 创建单层目录 | 父目录需存在 |
| `os.makedirs(path)` | 递归创建多层目录 | 常用 |
| `os.rmdir(path)` | 删除空目录 | 非空会报错 |
| `os.remove(path)` | 删除文件 | 文件不存在会报错 |
| `os.rename(src, dst)` | 重命名 / 移动 | — |

### 5. 遍历目录树 `os.walk`

```python
# os.walk 递归遍历目录，返回 (当前目录路径, 子目录列表, 文件列表)
for root, dirs, files in os.walk("."):
    for name in files:
        print(os.path.join(root, name))   # 打印每个文件的完整路径
```

### 6. 结合 `with` 的安全写法示例

```python
import os

# 基于脚本所在目录拼接文件路径，避免因工作目录不同而找不到文件
file_path = os.path.join(os.path.dirname(__file__), "test.txt")

if os.path.exists(file_path):
    with open(file_path, "r", encoding="utf-8") as f:
        print(f.read())
else:
    print("文件不存在：", file_path)
```

> **经验：** 用相对路径 `open("test.txt")` 时，Python 是在**当前工作目录**下找文件，而不一定是脚本所在目录。用 `os.path.dirname(__file__)` 拼接可彻底避免 `FileNotFoundError`。

## 十、`pathlib` 面向对象式路径操作

Python 3.4+ 提供了 `pathlib` 模块，用**面向对象**的方式操作路径，比 `os.path` 更简洁直观。

```python
from pathlib import Path

p = Path("test.txt")               # 创建路径对象
print(p.exists())                  # 是否存在
print(p.read_text(encoding="utf-8"))    # 直接读取全部文本
p.write_text("新内容", encoding="utf-8") # 直接写入文本

# 用 / 运算符拼接路径（非常直观）
base = Path(__file__).parent       # 脚本所在目录
target = base / "test.txt"

# 遍历目录下所有 .txt 文件
for txt in Path(".").glob("*.txt"):
    print(txt)
```

| 需求 | `os.path` 写法 | `pathlib` 写法 |
|------|---------------|---------------|
| 拼接路径 | `os.path.join(a, b)` | `Path(a) / b` |
| 判断存在 | `os.path.exists(p)` | `Path(p).exists()` |
| 取文件名 | `os.path.basename(p)` | `Path(p).name` |
| 取父目录 | `os.path.dirname(p)` | `Path(p).parent` |
| 读文本 | `open(p).read()` | `Path(p).read_text()` |

## 十二、常见错误与解决

| 错误类型 | 原因 | 解决方法 |
|----------|------|----------|
| `FileNotFoundError: [Errno 2] No such file or directory` | 路径写错，或工作目录与脚本目录不一致 | 检查文件名/扩展名；用 `os.path.join(os.path.dirname(__file__), 文件名)` 拼接绝对路径 |
| `io.UnsupportedOperation: not readable` | 用 `"w"` / `"a"` 等只写模式却调用了 `read()` | 想读就用带 `r` 的模式（`r` / `r+` / `a+`） |
| `io.UnsupportedOperation: not writable` | 用 `"r"` 只读模式却调用了 `write()` | 想写就用带 `w` / `a` 的模式 |
| 文件内容意外被清空 | 用了 `"w"` / `"w+"` 模式，打开即清空 | 想保留原内容用 `"a"`（追加）或 `"r+"` |
| `a+` 模式写入后 `read()` 读不到内容 | 写入后文件指针停在末尾 | 读取前先 `f.seek(0)` 把指针移回开头 |
| 中文乱码 / `UnicodeDecodeError` | 未指定编码，或编码与文件保存时不一致 | 打开时显式写 `encoding="utf-8"` |
| `PermissionError: [Errno 13] Permission denied` | 文件被其他程序占用（如已在 Excel 打开），或无权限 | 关闭占用该文件的程序，或以管理员权限运行 |
| `IsADirectoryError` | 用 `open()` 打开了一个目录而非文件 | 确认路径指向的是文件；目录操作请用 `os` 相关方法 |
| `FileNotFoundError` 删除不存在的文件 | `os.remove` / `os.rmdir` 目标不存在 | 删除前先用 `os.path.exists()` 判断 |
| `OSError: [WinError 145] Directory not empty` | 用 `os.rmdir` 删除了非空目录 | `os.rmdir` 只能删空目录；删非空目录用 `shutil.rmtree()` |
