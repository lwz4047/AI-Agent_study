## 一、面向对象是什么

**面向对象编程（OOP，Object-Oriented Programming）** 是一种以「对象」为核心的编程思想。

- **类（Class）**：对象的模板 / 图纸，描述一类事物共同的属性和行为。
- **对象（Object）**：根据类创建出来的具体实例（Instance）。

> 打个比方：**类**是「汽车设计图纸」，**对象**是「根据图纸造出来的一辆辆真车」。
> 同一张图纸可以造出无数辆车，每辆车都是独立的个体。

在本文件中，我们用 `Car`（汽车类）作为贯穿全程的例子。

## 二、定义一个类

使用 `class` 关键字定义类，类名习惯采用**大驼峰命名法**（如 `Car`、`Student`）。

```python
# 需求：定义一个汽车类
class Car:
    """汽车类"""
    pass    # pass 表示占位，表示空类，后续会加属性和方法
```

**要点说明：**

- `class Car:` —— 定义一个名为 `Car` 的类。
- `"""汽车类"""` —— 类的文档字符串（docstring），用于描述这个类的作用。
- `pass` —— 占位语句，表示类体暂时为空，后续再补充属性和方法。

## 三、创建对象（实例化）

**语法：** `对象名 = 类名()`

```python
# 创建对象（实例化对象）： 对象名 = 类名()
car1 = Car()
print(car1)   # <__main__.Car object at 0x000001EC3312D6A0> 对象的内存地址

# 第二次
car2 = Car()
print(car2)   # <__main__.Car object at 0x000001C6937B7D90> 对象的内存地址
```

**运行结果分析：**

```
<__main__.Car object at 0x000001EC3312D6A0>
<__main__.Car object at 0x000001C6937B7D90>
```

- 直接 `print(对象)` 打印出的是**对象的内存地址**。
- `car1` 和 `car2` 是两个**独立**的对象，它们的内存地址**不同**。

> **结论：** 每调用一次 `类名()`，就会创建一个全新的、独立的对象。

## 四、实例方法与 self

在类中定义的函数称为**方法**。带有 `self` 参数的方法叫做**实例方法**。

```python
# 需求：给汽车类添加两个方法 start 和 run
class Car:
    """汽车类"""
    def start(self):   # 实例方法：带有 self 参数，self 表示调用该方法的对象
        print("汽车启动！！")
        print("self", self)

    def run(self):
        print("汽车正在行驶")

# 创建对象
car = Car()
car.start()
print("car", car)     # self = car

car1 = Car()
car1.start()
print("car1", car1)   # self = car1
```

**self 的理解（重点）：**

| 概念 | 说明 |
|------|------|
| `self` | 代表**调用该方法的那个对象本身** |
| 谁调用 | `car.start()` → 此时 `self` 就是 `car` |
| 自动传参 | 调用时**不需要**手动传 `self`，Python 自动把对象传进去 |
| 必须写在首位 | 实例方法的第一个参数必须是 `self`（名字可自定义，但约定用 `self`） |

**验证：** 打印出的 `self` 内存地址与对应对象（`car` / `car1`）的地址一致，说明
`self` 确实指向调用方法的那个对象。

> **口诀：** `self` = 「我自己」，即当前正在调用方法的对象。

## 五、类属性

**类属性**是定义在类中、方法外的变量，它属于**类本身**，被该类的所有对象**共享**。

```python
class Car:
    # 类属性：所有汽车共享，轮子数量为 4
    wheel_count = 4

    def start(self):
        print("我可以启动了！！")

# 类和对象都可以访问类的属性
car = Car()
print(car.wheel_count)     # 4  （对象访问）

car1 = Car()
print(car1.wheel_count)    # 4  （另一个对象访问）

print(Car.wheel_count)     # 4  （类直接访问）
```

**要点说明：**

- `wheel_count = 4` 是**类属性**，所有 `Car` 对象共享同一份。
- 访问方式有两种：
  - **通过对象访问**：`car.wheel_count`
  - **通过类访问**：`Car.wheel_count`

> **类属性 vs 实例属性：**
> - **类属性**：属于类，所有对象共享（如所有汽车都有 4 个轮子）。
> - **实例属性**：属于每个对象自己，各不相同（如每辆车的颜色、品牌不同），在 `__init__` 中通过 `self.xxx` 定义。

## 六、构造函数 `__init__`

**构造函数**是一个特殊的方法，在**创建对象时自动调用**，用于**初始化对象的属性**。

```python
class Car:
    """汽车类"""
    wheel_count = 4            # 类属性

    # 构造函数
    def __init__(self, color, brand):
        self.color = color     # 实例属性：颜色
        self.brand = brand     # 实例属性：品牌

    def start(self):
        print(f"{self.color}的{self.brand}启动了")

# 创建对象，直接调用 __init__ 构造函数，初始化 (color, brand)
car = Car("红色", "小米SU7")
car.start()        # 红色的小米SU7启动了

car1 = Car("蓝色", "小米鹏程N90")
car1.start()       # 蓝色的小米鹏程N90启动了
```

**要点说明：**

| 概念 | 说明 |
|------|------|
| `__init__` | 构造函数名，前后各两个下划线（是 Python 的「魔术方法」） |
| 自动调用 | 创建对象 `Car("红色", "小米SU7")` 时**自动执行**，无需手动调用 |
| 参数传递 | 除 `self` 外的参数（`color`、`brand`）在实例化时按顺序传入 |
| `self.color = color` | 把传入的参数保存为**对象的实例属性** |

**执行流程：**

1. 写 `Car("红色", "小米SU7")` → Python 创建一个新对象。
2. 自动调用 `__init__`，把 `"红色"` 传给 `color`，`"小米SU7"` 传给 `brand`。
3. `self.color = color` 把值绑定到该对象上，完成初始化。
4. 之后就能通过 `car.color`、`car.brand` 访问这些属性。

> **注意：** 每个对象拥有各自独立的实例属性，`car` 是红色，`car1` 是蓝色，互不影响。

## 七、析构函数 `__del__`

**析构函数**也是一个魔术方法，当**对象被销毁（程序结束）时自动触发**。

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

    def __del__(self):   # 析构函数：程序结束、对象被销毁时自动触发
        print(f"{self.brand}被销毁了")

# 创建对象
car = Car("丰田")
```

**要点说明：**

| 概念 | 说明 |
|------|------|
| `__del__` | 析构函数名，前后各两个下划线 |
| 自动触发 | 当对象被销毁时（如程序运行结束）自动调用，无需手动执行 |
| 常见用途 | 释放资源、做一些「收尾清理」工作 |

**运行结果：** 程序结束时会自动输出：

```
丰田被销毁了
```

> **对比记忆：**
> - `__init__`（构造函数）：**对象出生**时自动调用 → 负责初始化。
> - `__del__`（析构函数）：**对象销毁**时自动调用 → 负责收尾清理。

## 八、知识点汇总

| 知识点 | 语法 / 关键 | 说明 |
|--------|-------------|------|
| 定义类 | `class 类名:` | 类名用大驼峰命名，如 `Car` |
| 创建对象 | `对象名 = 类名()` | 每次调用都生成独立的新对象 |
| 实例方法 | `def 方法(self):` | 带 `self` 参数，`self` 指向调用它的对象 |
| `self` | 方法第一个参数 | 代表对象本身，调用时自动传入，无需手动传 |
| 类属性 | 类中、方法外定义变量 | 属于类，所有对象共享 |
| 实例属性 | `self.xxx = 值` | 属于每个对象，各不相同 |
| 构造函数 | `def __init__(self, ...):` | 创建对象时自动调用，用于初始化属性 |
| 析构函数 | `def __del__(self):` | 对象销毁时自动调用，用于收尾清理 |

**面向对象三大特性的入门铺垫：**

本文件主要涉及「类与对象」的基础概念，后续还会学习面向对象的三大特性：

1. **封装**（见 `py_encapasulation.py`）：把属性和方法包裹在类中。
2. **继承**：子类复用父类的属性和方法。
3. **多态**：同一个方法在不同对象上有不同表现。

## 九、常见错误与解决

| 错误类型 | 原因 | 解决方法 |
|----------|------|----------|
| `TypeError: __init__() missing ... argument` | 实例化时没有给 `__init__` 传必需的参数 | 按 `__init__` 定义的参数顺序补齐，如 `Car("红色", "小米")` |
| `NameError: name 'self' is not defined` | 在方法外或忘记定义 `self` 就使用 | 实例方法第一个参数必须写 `self` |
| `AttributeError: 'Car' object has no attribute 'xxx'` | 访问了对象不存在的属性 | 确认属性已在 `__init__` 或类中定义 |
| 方法调用报错少了参数 | 忘记方法要带 `self`，或调用时手动传了 `self` | 定义时写 `self`，调用时用 `对象.方法()` 不传 `self` |
| 打印对象显示内存地址 | 未定义 `__str__` 方法 | 后续可学习定义 `__str__` 来自定义打印内容 |
