## 一、面向对象是什么

**面向对象编程（OOP，Object-Oriented Programming）** 是一种以「对象」为核心的编程思想。

- **类（Class）**：对象的模板 / 图纸，描述一类事物共同的属性和行为。
- **对象（Object）**：根据类创建出来的具体实例（Instance）。

> 打个比方：**类**是「汽车设计图纸」，**对象**是「根据图纸造出来的一辆辆真车」。
> 同一张图纸可以造出无数辆车，每辆车都是独立的个体。

在本文件中，我们用 `Car`（汽车类）作为贯穿全程的例子。

## 二、定义一个类

使用 `class` 关键字定义类，类名习惯采用**大驼峰命名法**（如 `Car`、`Student`）。

```python
# 需求：定义一个汽车类
class Car:
    """汽车类"""
    pass    # pass 表示占位，表示空类，后续会加属性和方法
```

**要点说明：**

- `class Car:` —— 定义一个名为 `Car` 的类。
- `"""汽车类"""` —— 类的文档字符串（docstring），用于描述这个类的作用。
- `pass` —— 占位语句，表示类体暂时为空，后续再补充属性和方法。

## 三、创建对象（实例化）

**语法：** `对象名 = 类名()`

```python
# 创建对象（实例化对象）： 对象名 = 类名()
car1 = Car()
print(car1)   # <__main__.Car object at 0x000001EC3312D6A0> 对象的内存地址

# 第二次
car2 = Car()
print(car2)   # <__main__.Car object at 0x000001C6937B7D90> 对象的内存地址
```

**运行结果分析：**

```
<__main__.Car object at 0x000001EC3312D6A0>
<__main__.Car object at 0x000001C6937B7D90>
```

- 直接 `print(对象)` 打印出的是**对象的内存地址**。
- `car1` 和 `car2` 是两个**独立**的对象，它们的内存地址**不同**。

> **结论：** 每调用一次 `类名()`，就会创建一个全新的、独立的对象。

## 四、实例方法与 self

在类中定义的函数称为**方法**。带有 `self` 参数的方法叫做**实例方法**。

```python
# 需求：给汽车类添加两个方法 start 和 run
class Car:
    """汽车类"""
    def start(self):   # 实例方法：带有 self 参数，self 表示调用该方法的对象
        print("汽车启动！！")
        print("self", self)

    def run(self):
        print("汽车正在行驶")

# 创建对象
car = Car()
car.start()
print("car", car)     # self = car

car1 = Car()
car1.start()
print("car1", car1)   # self = car1
```

**self 的理解（重点）：**

| 概念 | 说明 |
|------|------|
| `self` | 代表**调用该方法的那个对象本身** |
| 谁调用 | `car.start()` → 此时 `self` 就是 `car` |
| 自动传参 | 调用时**不需要**手动传 `self`，Python 自动把对象传进去 |
| 必须写在首位 | 实例方法的第一个参数必须是 `self`（名字可自定义，但约定用 `self`） |

**验证：** 打印出的 `self` 内存地址与对应对象（`car` / `car1`）的地址一致，说明
`self` 确实指向调用方法的那个对象。

> **口诀：** `self` = 「我自己」，即当前正在调用方法的对象。

## 五、类属性

**类属性**是定义在类中、方法外的变量，它属于**类本身**，被该类的所有对象**共享**。

```python
class Car:
    # 类属性：所有汽车共享，轮子数量为 4
    wheel_count = 4

    def start(self):
        print("我可以启动了！！")

# 类和对象都可以访问类的属性
car = Car()
print(car.wheel_count)     # 4  （对象访问）

car1 = Car()
print(car1.wheel_count)    # 4  （另一个对象访问）

print(Car.wheel_count)     # 4  （类直接访问）
```

**要点说明：**

- `wheel_count = 4` 是**类属性**，所有 `Car` 对象共享同一份。
- 访问方式有两种：
  - **通过对象访问**：`car.wheel_count`
  - **通过类访问**：`Car.wheel_count`

> **类属性 vs 实例属性：**
> - **类属性**：属于类，所有对象共享（如所有汽车都有 4 个轮子）。
> - **实例属性**：属于每个对象自己，各不相同（如每辆车的颜色、品牌不同），在 `__init__` 中通过 `self.xxx` 定义。

## 六、类方法与静态方法

> 本章节基于 `py_method.py` 整理。

Python 中的方法按「第一个参数」的不同，可分为三类：**实例方法**、**类方法**、**静态方法**。「四、实例方法与 self」已讲过实例方法，这里补充另外两种。

### 1. 三种方法的对比

| 方法类型 | 装饰器 | 第一个参数 | 能访问实例属性 | 能访问类属性 | 典型用途 |
|----------|--------|:---------:|:-------------:|:-----------:|----------|
| 实例方法 | 无 | `self` | ✅ | ✅ | 操作对象自身的数据 |
| 类方法 | `@classmethod` | `cls` | ❌ | ✅ | 操作类属性、工厂方法 |
| 静态方法 | `@staticmethod` | 无 | ❌ | ❌ | 与类相关的工具函数 |

### 2. 静态方法（`@staticmethod`）

静态方法用 `@staticmethod` 装饰，**不需要 `self` 或 `cls`**，本质是「放在类里的普通函数」。可直接通过**类名调用，无需创建对象**。

```python
class GeometryTool:
    """几何工具类"""
    @staticmethod                 # 静态方法
    def circle_area(radius):
        """计算圆的面积：πr²"""
        return 3.14 * radius ** 2

# 直接通过类名调用（推荐），不用创建对象
print(GeometryTool.circle_area(5))   # 78.5
```

**要点：** 静态方法内部**访问不到实例属性和类属性**（因为没有 `self` / `cls`），适合那些「逻辑上属于这个类、但不依赖任何数据」的工具函数。

### 3. 类方法（`@classmethod`）

类方法用 `@classmethod` 装饰，第一个参数是 `cls`，**代表类本身**（无需手动传入）。它可以访问和修改**类属性**，且被所有对象共享。

```python
class Person:
    average_age = 75              # 类属性：平均年龄

    @classmethod
    def get_average_age(cls):     # cls 代表类本身
        """获取平均年龄"""
        return cls.average_age

    @classmethod
    def set_average_age(cls, age):
        """设置平均年龄"""
        cls.average_age = age

# 方式一：通过类名调用（推荐）
Person.set_average_age(100)
print(Person.get_average_age())   # 100

# 方式二：通过对象调用（效果相同，改的都是同一份类属性）
person = Person()
person.set_average_age(99)
print(person.get_average_age())   # 99

person2 = Person()
print(person2.get_average_age())  # 99（类属性共享，随之改变）
```

**要点：**

- `cls.average_age` 指向**类属性**，无论用类名还是任意对象去修改，都会影响所有对象（因为共享同一份）。
- 类方法既能用**类名**调用，也能用**对象**调用，但推荐用类名，语义更清晰。
- 常见用途：操作类属性、实现「工厂方法」（用不同方式创建对象）。

> **对比记忆：**
> - **实例方法** → 用 `self` 操作「对象自己」的数据；
> - **类方法** → 用 `cls` 操作「整个类共享」的数据；
> - **静态方法** → 谁的数据都不操作，只是个挂在类里的工具函数。

## 七、构造函数 `__init__`

**构造函数**是一个特殊的方法，在**创建对象时自动调用**，用于**初始化对象的属性**。

```python
class Car:
    """汽车类"""
    wheel_count = 4            # 类属性

    # 构造函数
    def __init__(self, color, brand):
        self.color = color     # 实例属性：颜色
        self.brand = brand     # 实例属性：品牌

    def start(self):
        print(f"{self.color}的{self.brand}启动了")

# 创建对象，直接调用 __init__ 构造函数，初始化 (color, brand)
car = Car("红色", "小米SU7")
car.start()        # 红色的小米SU7启动了

car1 = Car("蓝色", "小米鹏程N90")
car1.start()       # 蓝色的小米鹏程N90启动了
```

**要点说明：**

| 概念 | 说明 |
|------|------|
| `__init__` | 构造函数名，前后各两个下划线（是 Python 的「魔术方法」） |
| 自动调用 | 创建对象 `Car("红色", "小米SU7")` 时**自动执行**，无需手动调用 |
| 参数传递 | 除 `self` 外的参数（`color`、`brand`）在实例化时按顺序传入 |
| `self.color = color` | 把传入的参数保存为**对象的实例属性** |

**执行流程：**

1. 写 `Car("红色", "小米SU7")` → Python 创建一个新对象。
2. 自动调用 `__init__`，把 `"红色"` 传给 `color`，`"小米SU7"` 传给 `brand`。
3. `self.color = color` 把值绑定到该对象上，完成初始化。
4. 之后就能通过 `car.color`、`car.brand` 访问这些属性。

> **注意：** 每个对象拥有各自独立的实例属性，`car` 是红色，`car1` 是蓝色，互不影响。

## 八、析构函数 `__del__`

**析构函数**也是一个魔术方法，当**对象被销毁（程序结束）时自动触发**。

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

    def __del__(self):   # 析构函数：程序结束、对象被销毁时自动触发
        print(f"{self.brand}被销毁了")

# 创建对象
car = Car("丰田")
```

**要点说明：**

| 概念 | 说明 |
|------|------|
| `__del__` | 析构函数名，前后各两个下划线 |
| 自动触发 | 当对象被销毁时（如程序运行结束）自动调用，无需手动执行 |
| 常见用途 | 释放资源、做一些「收尾清理」工作 |

**运行结果：** 程序结束时会自动输出：

```
丰田被销毁了
```

> **对比记忆：**
> - `__init__`（构造函数）：**对象出生**时自动调用 → 负责初始化。
> - `__del__`（析构函数）：**对象销毁**时自动调用 → 负责收尾清理。

## 九、封装（Encapsulation）

> 本章节基于 `py_encapasulation.py` 整理。

**封装**是面向对象三大特性之一：**把对象的属性（数据）和方法（行为）包裹在类内部**，对外隐藏敏感的实现细节，只暴露必要的「接口」供外部调用。

> 生活比喻：银行账户的「余额」是敏感数据，不能让别人随便改。我们通过「存款 / 取款 / 查询」这些**受控接口**来操作余额，接口内部可以加入验证逻辑。

### 1. 公开属性与私有属性

在属性名前加**两个下划线 `__`**，该属性就变成**私有属性**，外部无法直接访问。

```python
class BankAccount:
    def __init__(self, name, balance):
        self.name = name          # 公开属性：外部可直接访问
        self.__balance = balance  # 私有属性：属性名前加两个下划线 __

    def check_balance(self):      # 接口1：查询余额
        print(f"{self.name}的账户余额为{self.__balance}元。")

    def deposit(self, amount):    # 接口2：存款（带验证）
        if amount > 0:
            self.__balance += amount
            print("存款成功！！", f"存款金额为{self.__balance}元")
        else:
            print("存款失败")

    def withdraw(self, amount):   # 接口3：取款（带验证）
        if amount < 0 or amount > self.__balance:
            print("取款失败")
        else:
            self.__balance -= amount
            print("取款成功!!", f"取款金额为{self.__balance}元")
```

### 2. 私有属性无法在外部直接访问

```python
account = BankAccount("小米", 1000)
account.check_balance()   # ✅ 通过接口访问
print(account.__balance)  # ❌ AttributeError: 'BankAccount' object has no attribute '__balance'
```

### 3. 名称改写（Name Mangling）——「强行」访问私有属性

私有属性并非绝对无法访问，Python 只是对它做了**名称改写**：类内部的 `__balance` 会被改写成 `_类名__balance`。

```python
print(account._BankAccount__balance)  # 1000（能访问，但不推荐这样用）
```

**三种访问权限对照：**

| 写法 | 名称 | 说明 |
|------|------|------|
| `name` | 公开属性 | 任何地方都能访问 |
| `_name` | 受保护属性（约定） | 单下划线只是「约定俗成」的提醒，实际仍可外部访问 |
| `__name` | 私有属性 | 双下划线触发名称改写，外部无法用原名访问 |

### 4. 封装的好处

- **保护数据安全**：隐藏内部实现细节，余额不能被外部随意篡改。
- **加入验证逻辑**：如取款金额不能为负、不能超出余额。
- **降低耦合**：外部只依赖接口，内部实现可自由修改而不影响调用方。

### 5. 补充：使用 `@property` 优雅地读写私有属性

除了自定义 `get_xxx` / `set_xxx` 方法，Python 提供了 `@property` 装饰器，让我们能**像访问普通属性一样**读写私有属性，同时保留验证逻辑。

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    @property
    def balance(self):        # getter：读取时自动调用
        return self.__balance

    @balance.setter
    def balance(self, value): # setter：赋值时自动触发验证
        if value >= 0:
            self.__balance = value

acc = BankAccount(100)
print(acc.balance)  # 100，像读属性一样读取
acc.balance = 200   # 像赋值一样写入，内部自动走 setter 验证
```

## 十、继承（Inheritance）

> 本章节基于 `py_inheritance.py` 整理。

**继承**：**子类自动获得父类的属性和方法**，实现代码复用。子类还可以在继承的基础上扩展新功能或重写父类方法。

> 生活比喻：`动物（Animal）` 会吃、会睡；`狗（Dog）`、`猫（Cat）` 都是动物，天然拥有这些能力，同时又有各自特有的行为。

### 1. 基本语法

```python
class 子类(父类):
    pass
```

### 2. 多层继承（继承的传递性）

子类继承父类，父类又继承爷爷类，子类会**间接拥有整条继承链上的所有属性和方法**。

```python
class Living:              # 爷爷类
    features = "有生命"
    def breathe(self):
        print("有呼吸")

class Animal(Living):      # 父类，继承 Living
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def eat(self):
        print(f"{self.name}在吃东西！")

class Dog(Animal):         # 子类，继承 Animal（也间接继承 Living）
    def bark(self):        # 子类特有方法
        print("小狗汪汪叫")

dog = Dog("旺财", 1)
dog.eat()      # 继承自 Animal
dog.bark()     # 自己的方法
dog.breathe()  # 间接继承自 Living
```

### 3. 方法重写（Override）与 `super()`

子类可以**重写**父类的同名方法，实现自己的逻辑；用 `super()` 可以在重写时**保留并调用父类原有逻辑**。

```python
class Cat(Animal):
    def make_sound(self):     # 重写父类方法
        super().make_sound()  # 先调用父类的实现
        print("猫咪喵喵喵")    # 再追加自己的逻辑
```

> `super()` 会自动找到父类对应的方法，常用于「扩展而非完全替换」父类行为的场景。

### 4. 多继承（一个子类有多个父类）

```python
class Watch:
    def show_time(self):
        print("当前时间：16:25")

class HealthDevice:
    def check_heart_rate(self):
        print("当前心率：75次")

class SmartWatch(Watch, HealthDevice):  # 同时继承两个父类
    pass

sw = SmartWatch()
sw.show_time()         # 来自 Watch
sw.check_heart_rate()  # 来自 HealthDevice
```

### 5. 多继承的方法查找顺序（MRO）

当多个父类有同名方法时，Python 按 **MRO（Method Resolution Order，方法解析顺序）** 从左到右查找，找到第一个就用。

```python
class Phone:
    def take_photo(self):
        print("手机拍照")

class Camera:
    def take_photo(self):
        print("相机拍照")

class CameraPhone(Phone, Camera):
    pass

c = CameraPhone()
c.take_photo()              # 手机拍照（先找到 Phone 的）
Camera.take_photo(c)        # 相机拍照（用「类名.方法(对象)」显式指定）
print(CameraPhone.__mro__)  # 查看方法解析顺序
```

MRO 顺序为：`CameraPhone -> Phone -> Camera -> object`。

> **补充：** 想绕过 MRO 强制调用某个父类的方法，可以用 `父类名.方法(对象)` 的写法，如 `Camera.take_photo(c)`。

### 6. 继承 vs 组合（重要设计思想）

**组合（Composition）**：不通过继承，而是在类中**持有另一个类的对象**来使用其功能（has-a 关系），这是替代多继承的更灵活方案。

```python
class SmartWatch(Watch):        # 只继承 Watch
    def __init__(self):
        self.hd = HealthDevice()  # 组合：内部创建一个 HealthDevice 实例

sw = SmartWatch()
sw.show_time()              # 继承来的
sw.hd.check_heart_rate()    # 通过组合进来的对象调用
```

| 对比 | 继承（is-a） | 组合（has-a） |
|------|-------------|--------------|
| 关系 | 子类「是一种」父类 | 类中「有一个」其他对象 |
| 耦合度 | 较强 | 较弱，更灵活 |
| 使用建议 | 谨慎使用多层 / 多继承 | 优先考虑组合 |

## 十一、多态（Polymorphism）

> 本章节基于 `py_polymorphism.py` 整理。

**多态**：**同一个方法（接口），作用在不同对象上，会产生不同的行为表现**，即「一个接口，多种形态」。

### 1. 多态的三个实现条件

1. 有**继承**关系（子类继承父类）；
2. 子类**重写**父类的方法；
3. **父类引用指向子类对象**（用统一接口去调用不同的子类对象）。

```python
class Pet:                 # 父类，定义统一接口
    def eat(self):
        print("宠物吃东西~")

class Dog(Pet):            # 子类重写
    def eat(self):
        print("狗吃骨头~")

class Cat(Pet):
    def eat(self):
        print("猫吃鱼~")

class Master:
    def feed(self, pet):   # 统一接口，接收任意宠物
        print("给宠物喂食~")
        pet.eat()          # 同一方法名，不同对象有不同表现

master = Master()
master.feed(Dog())   # 狗吃骨头~
master.feed(Cat())   # 猫吃鱼~
```

### 2. 多态的好处

- **扩展性强**：新增一种宠物（如 `Pig`、`Rabbit`），`Master.feed()` 无需修改就能直接使用。
- **接口统一**：调用方只关心对象「有没有 eat 方法」，不关心具体是哪一种对象。

### 3. 鸭子类型（Duck Typing）—— Python 特有的多态

> 「如果它走起来像鸭子、叫起来像鸭子，那它就是鸭子。」

Python **不强制要求继承同一个父类**，只要对象拥有对应的方法，就能被统一调用。

```python
class WeChatPay:
    def pay(self, money):
        print(f"微信支付：扣除{money}元")

class Alipay:
    def pay(self, money):
        print(f"支付宝支付：扣除{money}元")

class Bank:
    def pay(self, money):
        print(f"银行卡支付：扣除{money}元")

def pay_order(pay_obj, money):  # 不管什么对象，只要有 pay 方法即可
    pay_obj.pay(money)

pay_order(WeChatPay(), 100)
pay_order(Alipay(), 500)
pay_order(Bank(), 500)
```

这三个类之间**没有继承关系**，但都实现了 `pay` 方法，因此都能传给 `pay_order` 使用 —— 这就是鸭子类型。

### 4. 补充：类型判断 `isinstance` 与 `issubclass`

```python
dog = Dog()
print(isinstance(dog, Dog))   # True：dog 是 Dog 的实例
print(isinstance(dog, Pet))   # True：dog 也是父类 Pet 的实例
print(issubclass(Dog, Pet))   # True：Dog 是 Pet 的子类
```

| 函数 | 作用 |
|------|------|
| `isinstance(对象, 类)` | 判断「对象」是否为「类」（或其子类）的实例 |
| `issubclass(子类, 父类)` | 判断「子类」是否继承自「父类」 |

## 十二、知识点汇总

| 知识点 | 语法 / 关键 | 说明 |
|--------|-------------|------|
| 定义类 | `class 类名:` | 类名用大驼峰命名，如 `Car` |
| 创建对象 | `对象名 = 类名()` | 每次调用都生成独立的新对象 |
| 实例方法 | `def 方法(self):` | 带 `self` 参数，`self` 指向调用它的对象 |
| `self` | 方法第一个参数 | 代表对象本身，调用时自动传入，无需手动传 |
| 类属性 | 类中、方法外定义变量 | 属于类，所有对象共享 |
| 实例属性 | `self.xxx = 值` | 属于每个对象，各不相同 |
| 构造函数 | `def __init__(self, ...):` | 创建对象时自动调用，用于初始化属性 |
| 析构函数 | `def __del__(self):` | 对象销毁时自动调用，用于收尾清理 |
| 类方法 | `@classmethod` + `def 方法(cls):` | `cls` 代表类本身，可访问/修改类属性，类名或对象均可调用 |
| 静态方法 | `@staticmethod` | 无 `self`/`cls`，是与类相关的工具函数，直接用类名调用 |
| 封装 | `self.__xxx` | 私有属性用双下划线前缀，通过方法接口受控访问 |
| 名称改写 | `_类名__xxx` | 私有属性被改写，可「强行」访问（不推荐） |
| 继承 | `class 子类(父类):` | 子类复用父类的属性和方法 |
| 方法重写 | 子类定义同名方法 | 覆盖父类逻辑，可用 `super()` 调用父类方法 |
| 多继承 / MRO | `class C(A, B):` | 按 MRO 从左到右查找方法，`类名.__mro__` 可查看 |
| 组合 | `self.obj = 其他类()` | has-a 关系，比多继承更灵活 |
| 多态 | 统一接口调用不同对象 | 继承 + 重写 + 父类引用指向子类对象 |
| 鸭子类型 | 有对应方法即可调用 | Python 特有，无需继承同一父类 |

**面向对象三大特性总结：**

| 特性 | 核心思想 | 一句话概括 |
|------|----------|------------|
| 封装 | 隐藏细节、暴露接口 | 把属性和方法包起来，保护数据 |
| 继承 | 代码复用、层次扩展 | 子类自动拥有父类的能力 |
| 多态 | 一个接口、多种形态 | 同一方法在不同对象上有不同表现 |

## 十三、常见错误与解决

| 错误类型 | 原因 | 解决方法 |
|----------|------|----------|
| `TypeError: __init__() missing ... argument` | 实例化时没有给 `__init__` 传必需的参数 | 按 `__init__` 定义的参数顺序补齐，如 `Car("红色", "小米")` |
| `NameError: name 'self' is not defined` | 在方法外或忘记定义 `self` 就使用 | 实例方法第一个参数必须写 `self` |
| `AttributeError: 'Car' object has no attribute 'xxx'` | 访问了对象不存在的属性 | 确认属性已在 `__init__` 或类中定义 |
| 方法调用报错少了参数 | 忘记方法要带 `self`，或调用时手动传了 `self` | 定义时写 `self`，调用时用 `对象.方法()` 不传 `self` |
| 打印对象显示内存地址 | 未定义 `__str__` 方法 | 后续可学习定义 `__str__` 来自定义打印内容 |
| `AttributeError: object has no attribute '__xxx'` | 在外部直接访问了私有属性 | 私有属性需通过类的方法（接口）访问 |
| 子类调用父类方法报错 / 逻辑丢失 | 重写时未调用父类原有逻辑 | 在重写方法中用 `super().方法()` 先调用父类 |
| 多继承调用了「错误」父类的同名方法 | 未理解 MRO 查找顺序 | 用 `类名.__mro__` 查看顺序，或 `父类名.方法(对象)` 显式指定 |
| `TypeError: xxx() takes 1 positional argument but 2 were given` | 静态方法定义时误加了 `self`，或调用类方法时手动多传了参数 | 静态方法不要写 `self`/`cls`；类方法第一个参数是 `cls`，调用时不手动传 |
| `NameError: name 'cls' is not defined` | 在普通方法里用了 `cls`，或类方法忘记加 `@classmethod` | 想用 `cls` 必须加 `@classmethod` 装饰器，并把 `cls` 作为第一个参数 |
| 静态方法里访问 `self.xxx` / `cls.xxx` 报错 | 静态方法没有 `self`/`cls`，无法访问实例或类属性 | 需要访问数据就改用实例方法（`self`）或类方法（`cls`） |
| 通过一个对象改了类属性，其他对象也跟着变 | 类属性被所有对象共享，`cls.xxx = 值` 改的是同一份 | 若需每个对象独立，应改用实例属性 `self.xxx` |
